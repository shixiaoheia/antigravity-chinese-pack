# Antigravity（反重力）简体＋繁體中文汉化

Google Antigravity **Desktop 2.22.0 · Windows** 的社区汉化包，提供简体中文和繁體中文。安装工具会自动备份原文件，也可以双击还原英文。

**适用范围：仅支持已核对的 Desktop 2.22.0 构建。** 同样写着 2.22.0 的其他构建也可能不兼容，工具会检查并拒绝覆盖。不适用于独立的 Antigravity IDE 1.x，也不适用于 agy 命令行工具。请先在软件的「Help / 帮助 → About / 关于」确认产品与版本。

## 第一步：下载合并包

[下载简体＋繁體合并 ZIP](https://github.com/shixiaoheia/antigravity-chinese-pack/releases/download/v2.22.0-cn-r2-tw-r1/Antigravity-2.22.0-Chinese-Pack.zip)

**只需下载这一个 ZIP，两种语言都在里面。** 解压后打开「简体中文」或「繁體中文」文件夹，安装你想用的一种即可，不需要把两种都安装一遍。

[打不开下载链接？进入发布页面，在 Assets 下选择 `Antigravity-2.22.0-Chinese-Pack.zip`](https://github.com/shixiaoheia/antigravity-chinese-pack/releases/tag/v2.22.0-cn-r2-tw-r1)。

请下载上面的汉化合并包。GitHub 自动生成的 `Source code (zip)` 是仓库源码，初次安装请使用合并包。

## 第二步：解压

1. 找到下载的 ZIP，通常在 Windows 的「下载」文件夹。
2. 右键 ZIP → 选择「全部解压缩」→ 点击「提取」。
3. 打开解压出来的总文件夹，先看「先看我-安装教程.txt」，再打开「简体中文」或「繁體中文」，直到能看见安装文件、`manifest.json` 和 `patch.dat`。

**不要在压缩包预览窗口里双击安装，也不要只取出一个安装文件。** 文件夹里的文件要放在一起。

## 第三步：关闭 Antigravity

先保存正在做的工作，再退出 Antigravity。如果任务栏右下角的托盘里还有它的图标，也退出它。安装时软件不能继续运行；工具不会替你强制关闭软件。

## 第四步：双击安装

| 你打开的语言文件夹 | 要双击的文件 |
| --- | --- |
| 简体中文 | `双击安装汉化.cmd` |
| 繁體中文 | `雙擊安裝漢化.cmd` |

等窗口显示安装成功，再按任意键关闭窗口。重新打开 Antigravity，界面就会使用所选中文。

通常不需要管理员权限，也不用安装 Node.js、Python 或其他工具。安装工具本身不需要联网下载依赖。

如果提示「未自动找到安装目录」，粘贴**包含 `Antigravity.exe` 的文件夹路径**并按回车；不要选择 `resources` 文件夹。可以右键 Antigravity 快捷方式 →「打开文件所在的位置」来寻找它。

## 想恢复英文？

保存工作并退出软件，然后在**当前安装版本的汉化包**里双击：

- 简体：`双击还原英文.cmd`
- 繁體：`雙擊還原英文.cmd`

提示还原成功后，再打开软件即可。

安装时会保留原版备份：`安装目录\resources\app.asar.agy-zh-CN-2.22.0.original`。两种语言共用这个备份文件，名字里有 `zh-CN` 是正常的。**请不要删除或改名。**

## 已经装过汉化，怎么升级或换语言？

下表只适用于本项目的对应版本；其他来源的汉化不能直接覆盖。

| 当前状态 | 想安装的版本 | 操作 |
| --- | --- | --- |
| 原版英文 | 简体 r2 / 繁體 r1 | 直接安装 |
| 本项目旧简体 r1 | 简体 r2 | 直接安装简体 r2 |
| 本项目简体 r1 / r2 | 繁體 r1 | 直接安装繁體 r1，保留原版备份 |
| 本项目繁體 r1 | 简体 r2 | 先用繁體包还原英文，再安装简体 r2 |

更新或切换前，都要保存工作并退出软件。升级后使用新包的还原工具，旧工具可能无法识别新补丁。

## 遇到问题，先看这里

| 看到的情况 | 怎么办 |
| --- | --- |
| 提示软件还在运行 | 保存工作并退出软件和托盘进程，再运行安装文件 |
| 提示版本或构建不匹配 | 本包不支持当前文件；不要手动覆盖，也不要删除校验。等待适配版本 |
| 提示补丁校验失败或文件找不到 | 重新下载 ZIP 并完整解压，让文件都留在同一文件夹 |
| 提示找不到原版备份 | 找回最初安装时保存的备份，再尝试升级或还原 |
| 提示没有写入权限 | 确认软件已退出；若软件装在受保护的目录，可右键对应安装文件选择「以管理员身份运行」 |
| 官方更新后又变英文 | 官方更新可能替换程序文件；只有构建仍匹配时才能重新安装。本包不适配新版本 |
| 仍有少量英文 | 新增服务端文案、第三方插件和部分动态页面可能没有匹配词条；可提交截图和页面位置 |
| 出现「地区不支持」或智能体请求失败 | 这是账号、地区资格或服务请求问题，汉化包不能修复这类错误 |

反馈漏译时，请注明 Desktop 版本、简体或繁體，以及所在页面。截图请先遮住账号、聊天内容和项目路径。

## 翻译内容与验证

- 简体 r2：2,757 条词条，补充 576 条、润色 156 条；处理拆分句子的中英混排，改进设置、权限、搜索和按钮提示。
- 繁體 r1：2,766 条词条，统一「檔案、專案、視窗、記憶體、權限」等表达，并补齐重试、错误编号和疑难排解提示。
- 保留模型名称与等级、用户自定义标题、项目名称、代码、输入内容和对话正文。
- 已验证差分补丁重建、脚本语法、Windows PowerShell 安装/升级/重复安装/还原、备份保留及不匹配构建拒绝覆盖。
- 独立界面测试覆盖动态文本、拆分句子、Shadow DOM、内容保护及更新菜单操作。完整报告在各包的验证报告 JSON 内。

验证报告记录的是发布前测试副本的结果，并非承诺每台电脑上的所有页面都已逐屏验收。汉化不改变账号资格、模型服务或网络配置，也不提供地区解锁。

## 项目内容与许可

`packages/` 保存发布包的安装工具、差分补丁、词条与测试报告；`src/` 保存界面翻译运行代码，方便查看和修订。下载包不包含完整 Antigravity 安装程序或原版 `app.asar`。
